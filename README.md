# Adentro · motor

Motor de producción de shorts del canal Adentro. Código visible, todos los derechos reservados (ver LICENSE).

- `scripts/voz.py` — narración con tiempos por palabra
- `scripts/montar.py` — voz, clips de fondo y mezcla de audio
- `scripts/render.js` — composición del video vertical
- `automatizacion/producir.sh` — guion → `entrega/es.mp4` y `entrega/en.mp4`
